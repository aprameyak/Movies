## About

**Movies** is a movie search application built with **React**, **TypeScript**, and **Vite** that queries the OMDb API to find films and series by title. Search results are displayed as cards with poster images, and clicking through navigates to a detail page with expanded metadata pulled live from the API.

## Features

- Title-based movie and TV series search via the OMDb API
- Search results page displaying poster, title, year, and media type for each match
- Detail view with full movie metadata fetched by IMDb ID
- Client-side routing between the home, results, and detail pages via React Router
- Background image styling and themed UI with custom CSS
- Built with Vite for fast development and optimized production bundles

## Technology Stack

- **Frontend**: React, TypeScript, Vite
- **Routing**: React Router
- **Data Source**: OMDb API (via Axios)
