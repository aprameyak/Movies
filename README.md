# Movie Search App

A React-based movie search application built with TypeScript and Vite.
ff
## Features

- Search for movies
- View movie details
- Responsive design

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Axios
